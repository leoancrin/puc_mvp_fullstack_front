# puc_mvp_fullstack_front
Repositório para o front-end do MVP da disciplina Desenvolvimento FullStack da Pós da PUC-Rio

## Descrição

Este repositório tem por função apresentar o código desenvolvido para o front-end da API de itens colecionáveis. É uma SPA (Single Page Application).

---

## Como acessar

Para acessar basta abrir o arquivo index.html diretamente no seu navegador.

### Como interagir com a API

A API responsável pelo back-end se encontra no repositório `https://github.com/leoancrin/puc_mvp_fullstack_api`. Para funcionar é necessário seguir os passos descritos no README.
